# 方程、数值语义与复现范围

科学依据是投向 *Expert Systems with Applications* 的 ESWA-D-26-05581R1 最终返修清稿。

投稿正文、投稿信与审稿回复不随代码发布；运行程序与出图不需要这些私有文件。

| 论文内容 | 独立实现 | 核对方式 |
| --- | --- | --- |
| SmoothMax–Greenshields 速度闭包 | `problem.py` 的 `speed`，稳定 logaddexp | 不直接计算大指数；配置 beta=5 |
| 强可控性 | 风速解析上界及采样检查 | 不满足 `v_min > wind_bound + margin` 时报错 |
| `v(rho) sqrt(grad(phi)^2+eps^2) - wind·grad(phi)=1` | `value.py` 的 `eikonal` | 保存自由域残差均值与 P95 |
| 硬目标边界和障碍 Softplus 势垒 | `Potential.forward` | 目标面 phi 精确为零；屏蔽障碍缓冲区残差 |
| `u=wind-v(rho) grad(phi)/norm_eps` | `evaluate` | 使用同一个价值网络的自动微分梯度 |
| `div(rho*u)=q` | `transport.py` | 一个内部面只有一个上风通量，邻接单元共享 |
| 外边界和障碍无通量 | 网格面通量直接置零 | 审计实际面通量，不用 NN 边界残差替代 |
| 吸收目标 | 目标单元密度为零、单向上风吸收 | 阻止目标反向注入自由域 |
| Picard 松弛及裁剪 | `experiment.py` | 原始提案变化、接受变化、移除质量分别记录 |
| 独立 FSM–FVM 对照 | `reference.py`、`fsm_kernel.cpp` | 无风各向同性、8 方向扫掠，OpenMP 波前并行 |
| 单体 PINN 对照 | `baselines.py` | 自动微分连续性、软外边界通量；实际神经通量积分审计 |

论文给出的 NN 宽度 `[64,128,128,64]`、tanh、Softplus、Adam 学习率 1e-3、5000 PDE 点、1000 边界相关采样点、eps=1e-4、势垒 0.08/0.05、缓冲区 2、alpha=0.2、50 次外迭代、接受密度变化阈值 1e-3，以及网格规格均在基础配置中保留。由于目标条件硬编码，混合求解器的额外边界相关点是近外壁的内部 PDE 采样，没有添加软目标损失。

文中没有完整给出每个场景的几何、源强、自由速度、拥堵密度和风场函数系数。本次明确选择 `[0,100]×[0,100]×[0,30]`、球形源/目标、AABB 障碍及解析风场，并在每次输出的 `config.yaml` 中保存完整参数。验证配置采用较小源强以观察无裁剪条件下的守恒；这不是从旧代码抄出的实验参数。没有把论文某次运行的数字填入新结果。

保守上风算子使用 float64，PINN 使用 float32。面速度取相邻单元速度均值；外壁和障碍面通量为零。显式时间步按所有单元的总出流系数确定 CFL=0.8，而不是分别对单个方向估算 CFL。每步质量变化应满足：

`M_next - M = dt * (source_rate - target_absorption)`。

CPU 和 CUDA 图后端求解同一个稀疏算子。CUDA 图批量执行 100 步，图内逐步维护质量账本的最大误差，批次末核查有限性、非负性和停止条件。没有取消守恒检查来提高基准速度。CPU/GPU 密度一致性由独立通道测试及主网格基准核对。

内层需同时满足相对更新、离散连续性残差和全局质量差阈值。外层沿用论文的接受密度变化阈值，另要求内层收敛、接受场全局质量差小于 0.1%、最终接受场连续性相对残差小于 1e-3 且本轮没有裁剪损失。报告中连续性残差与 Picard 收敛分别显示；外层停止不等于两个 PDE 在所有点上精确成立。

从纯 Eikonal 残差开始的低预算版本产生过错误局部极小值；即使采样残差低，速度场也可能把源区引入无吸收出口的连通分量。这些运行保留为未收敛记录。验证配置增加明确披露的两项分支选择机制：

1. 由控制动力学推导 26 邻域有向旅行时间图，检查跨障碍线段后，预训练价值网络；图场只参与初始化。
2. 单侧短步 Bellman 不等式抑制错误局部极小值；候选方向包括离散方向、目标方向和当前诱导运动方向。附加当前运动方向可减轻固定角度模板本身引入的误差。

另外，非初始外迭代先检查自由域 PINN 残差：均值小于 0.02 且 P95 小于 0.12 时跳过重复优化，仍重新计算速度及输运。这是明确记录的非精确内层优化策略，用于减少训练开销和随机优化导致的速度扰动。续算保持物理参数和停止阈值，增加训练预算并缩短 Bellman 试探步；之前的未收敛结果保留。

checkpoint 保存累计裁剪质量，续算不会把历史裁剪账本清零。旧格式 checkpoint 必须
同时具备邻接的 `picard.csv` 和 `metadata.json` 及其引用的续算链；缺失审计历史会报错。

加速还包括 NumPy 数组直接拼接稀疏矩阵条目，避免在主网格上生成数百万个 Python 标量；不同场景用 spawn 进程并行；FSM 使用七点模板的波前依赖关系将同一波前的单元分配给多个 CPU 线程。可选 C++ 核编译到 `build/`，编译器及源码/库散列一起记录。

本次实现和运行覆盖纯平流混合主流程、八种基础风场/障碍组合、主网格代表场景和两个无风对照。也实现了静态网格风场插值与其他速度闭包接口。论文的全部敏感性扫描、强化单体 PINN 变体、连续注入 ABM 和可选扩散项不在当前结果中，图表只表示实际执行的实验。
